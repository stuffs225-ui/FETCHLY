# نبضنا

مكان صغير خاص بشخصين: قلبان ينبضان معًا عندما تدخلان، وزجاجات في بحر تخرج منها رسالة عشوائية.

## الفكرة
- **نبضنا:** كل واحد يرى قلب الثاني. إذا غاب يظهر قلبه خافتًا مع آخر مرة دخل، وإذا دخل يشتعل قلبه. إذا اجتمعتما يتقاربان وينبضان بنفس اللحظة على الجهازين (متزامنين على ساعة الخادم) مع اهتزاز وبتلات. لمس قلب الآخر يجعله يخفق أسرع عنده وعندك.
- **البحر:** تكتب (أو تسجّل صوتك) زجاجة وترميها. الطرف الثاني يهزّ جواله أو يضغط فتخرج له زجاجة **عشوائية** (السحب على الخادم بـ CSPRNG، والجديدة أرجح 3:1). الزجاجات المفتوحة تُحفظ عنده، وتعرف متى فُتحت زجاجتك.
- إشعارات (Web Push) عندما يدخل الآخر وأنت بعيد أو يرمي زجاجة، وتثبيت على الشاشة الرئيسية (PWA).

## التشغيل
```bash
npm install
cp .env.example .env      # ضع ROOM_PASSPHRASE: الكلمة السرّية بينكما
npm run server:dev        # الخادم على 4000
npm run dev               # الواجهة على 5173
```
للإنتاج: `npm start` (يبني الواجهة ويخدم كل شيء من منفذ واحد). **مهم:** الإشعارات والمايك وحساس الهز تتطلب HTTPS في الإنتاج، وعلى الآيفون يجب «إضافة إلى الشاشة الرئيسية» أولًا لتعمل الإشعارات.

## البنية
- `server/` — Express + WebSocket (`ws`) + SQLite (`better-sqlite3`)؛ الحضور والتزامن في `live.js`، الزجاجات في `bottles.js`، الإشعارات في `push.js` (مفاتيح VAPID تُولَّد وتُحفظ تلقائيًا).
- `src/` — React + Tailwind v4 + Framer Motion. `HeartStage.tsx` محرّك النبض، `Sea.tsx` مشهد البحر.
- البيانات والتسجيلات الصوتية في `server/data/` (خارج git) — احتفظ بنسخة احتياطية منها.

## الأمان
كلمة سر مشتركة (مقارنة آمنة زمنيًا + تحديد محاولات)، كوكي موقّع httpOnly، فحص Origin للكتابة والـ WebSocket، والصوت لا يُسمع قبل أن يسحب المستلم الزجاجة.

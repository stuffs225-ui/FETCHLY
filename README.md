# نبضنا

مكان صغير خاص بشخصين: قلبان ينبضان معًا، والمسافة بينهما على الشاشة هي المسافة الحقيقية، وزجاجات في بحر تخرج منها رسالة عشوائية. مصمم للجوال فقط.

## كيف يشتغل
- **الدخول:** موقع واحد ورابط واحد. تختار «أنا هي» أو «أنا هو»، وأول مرة كل واحد يضع رمزه لنفسه ويُحفظ على جواله أكثر من سنة (لا يُطلب إلا لو غيّر جواله). بعد ٨ محاولات خاطئة يُقفل ذلك الاختيار ١٥ دقيقة. لو نسي أحدكما رمزه، يمسحه الآخر من **الإعدادات** فيختار رمزًا جديدًا. لا توجد أسماء في أي مكان. **رمز الدعوة:** يُطلب فقط عند حجز مكان حرّ (أول مرة، أو بعد أن يمسح أحدكما رمز الآخر). بعد أن يدخل الاثنان يختفي من الإعدادات ولا يؤثر على أحد.
- **نبضنا:** كل واحد يرى قلب الثاني (يتحدّث كل بضع ثوانٍ). عندما يكونان معًا ينبضان بنفس اللحظة (متزامنين على ساعة الخادم). لمس قلب الآخر يجعله يخفق أسرع عنده وعندك.
- **المسافة:** بعد موافقة واحدة على الموقع، يتباعد القلبان أو يقتربان حسب المسافة الحقيقية، ويظهر الرقم (متر/كم). يُقرأ الموقع فقط أثناء فتح الموقع. الطرف الثاني يستلم المسافة فقط، والإحداثيات لا تغادر الخادم.
- **المشاركات:** تبويب فيه قائمة مشتركة لروابط **يوتيوب وإنستغرام وتيك توك**. تلصق الرابط فتظهر بطاقة بصورة الفيديو وعنوانه (من oEmbed بدون مفاتيح؛ إنستغرام بلا عنوان). تحاول الصفحة تشغيله **داخل الموقع** دائمًا: يوتيوب بمشغّله المضمّن، وتيك توك وإنستغرام بإطار التضمين الرسمي. وإن كان لا يقبل التضمين (بعض فيديوهات يوتيوب) أو لم يشتغل، يوجد زر «فتح في…» ومن القائمة يفتح الضغط على المنصة نفسها. **صاحب الرابط فقط** يعدّل سطره/ثانية البدء أو يحذفه، والثاني يضع ♥. **استمعا معًا** لفيديوهات يوتيوب القابلة للتضمين: يبدأ التشغيل عند الاثنين من نفس الموضع محسوبًا على ساعة الخادم. على الآيفون تتوقف الأغنية عند قفل الشاشة (قيد من يوتيوب).
- **البحر:** يكتب (أو يسجّل صوته) زجاجة ويرميها. الآخر يهزّ جواله أو يضغط فتخرج له زجاجة **عشوائية** (السحب على الخادم، والجديدة أرجح 3:1).
- **الألوان:** ثلاث ثيمات هادئة (ليل هادئ، ورق دافئ، أزرق ناعم) تُبدَّل من الإعدادات، وتُحفظ لكل جوال.
- لا إشعارات ولا حسابات ولا تنزيل.

## النشر على Vercel (مرة واحدة)
1. ارفع المستودع على Vercel (Import Git Repository) — الإعدادات تُكتشف تلقائيًا من `vercel.json`، وتأكد أن الفرع المنشور هو الذي فيه هذا الكود.
2. قاعدة البيانات — أحد خيارين:
   - **Supabase بدون كلمة سر:** يكفي وجود `SUPABASE_URL` (أو `NEXT_PUBLIC_SUPABASE_URL`) و`SUPABASE_SERVICE_ROLE_KEY` في Vercel. أول مرة يعرض الموقع شاشة فيها كود SQL: انسخه والصقه في Supabase ← SQL Editor ← Run (مرة واحدة). الجداول كلها تبدأ بـ `nb_` ومحمية بـ RLS، فلا تتداخل مع جداولك ولا يقرؤها المفتاح العام.
   - **أي Postgres برابط اتصال:** متغيّر `DATABASE_URL` أو `POSTGRES_URL`، وتُنشأ الجداول تلقائيًا.
3. **Deployments ← Redeploy** (المتغيّرات لا تصل للنشر القديم).
4. افتح الموقع، اختر «أنا هي» أو «أنا هو»، وضع رمزك. أرسل لها رابط الموقع نفسه (الرابط واحد للاثنين) فتفعل مثلك.

**مهم:** افتحا الموقع وضعا رمزيكما فور النشر، لأن أول من يختار «هي» أو «هو» يضع الرمز.

**مهم — حتى يفتح الرابط عندها مباشرة:** الفروع غير الرئيسية تُنشر كمعاينة (Preview) وتكون محمية بتسجيل دخول Vercel. اجعل هذا الفرع هو فرع الإنتاج: Settings ← Environments ← Production ← Branch Tracking (أو Settings ← Git ← Production Branch) ثم أعد النشر، واستخدم عنوان الإنتاج العام.

لو ظهرت «قاعدة البيانات غير مربوطة» فلا يوجد متغيّر قاعدة بيانات في هذا النشر؛ ولو ظهرت «تعذّر الاتصال بقاعدة البيانات» فالرابط موجود لكن الاتصال فشل وسبب الفشل مكتوب تحتها.

## التشغيل محليًا
```bash
npm install
npm start     # يبني الواجهة ويشغّل الخادم + قاعدة Postgres مدمجة، بدون أي إعدادات
```
لو نسيا الرمزين معًا: في Supabase ← SQL Editor نفّذ `delete from nb_slots;` فيختاران رمزين جديدين.

## البنية
- `api/index.js` + `server/` — دالة Vercel واحدة بلا أطر خارجية (`handler.js`: الحضور والمسافة والزجاجات والدخول) مع Postgres عبر `pg` (Supabase/Neon في الإنتاج). الحضور بالاستطلاع الخفيف (كل ٢٫٥–٦ ثوانٍ، بطلب واحد لقاعدة البيانات عبر الدالة `nb_sync`) والتزامن على ساعة الخادم.
- `src/` — React + Tailwind v4 + Framer Motion. `HeartStage.tsx` محرّك النبض والمسافة، `Sea.tsx` مشهد البحر، الثيمات في `index.css` و`lib/theme.ts`.
- البيانات والتسجيلات الصوتية في قاعدة البيانات.

الموقع القديم (FETCHLY) في تاريخ git عند الـ commit `8fbeda1`.

## تحديث قاعدة البيانات
عند أي تحديث يغيّر الجداول يعرض الموقع شاشة «خطوة واحدة في Supabase» من جديد (يقارن رقم النسخة `schemaVersion`). انسخ الكود والصقه في SQL Editor ثم Run؛ الكود آمن لو أعدته.

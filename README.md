# نبضنا

مكان صغير خاص بشخصين: قلبان ينبضان معًا، والمسافة بينهما على الشاشة هي المسافة الحقيقية، وزجاجات في بحر تخرج منها رسالة عشوائية. مصمم للجوال فقط.

## كيف يشتغل
- **الدخول:** لكل شخص رابط سرّي (A = هي، B = هو)، ويعرضهما الموقع لصاحبه في أول فتح. أول مرة يفتح رابطه يضع كلمة سرّ، ويُحفظ على الجوال أكثر من سنة. كلمة السرّ لا تُطلب إلا لو غيّر جواله أو مسح بيانات المتصفح. لا توجد أسماء في أي مكان.
- **نبضنا:** كل واحد يرى قلب الثاني. عندما يكونان معًا ينبضان بنفس اللحظة (متزامنين على ساعة الخادم). لمس قلب الآخر يجعله يخفق أسرع عنده وعندك.
- **المسافة:** بعد موافقة واحدة على الموقع، يتباعد القلبان أو يقتربان حسب المسافة الحقيقية، ويظهر الرقم (متر/كم). يُقرأ الموقع فقط أثناء فتح الموقع. الطرف الثاني يستلم المسافة فقط، والإحداثيات لا تغادر الخادم.
- **البحر:** يكتب (أو يسجّل صوته) زجاجة ويرميها. الآخر يهزّ جواله أو يضغط فتخرج له زجاجة **عشوائية** (السحب على الخادم، والجديدة أرجح 3:1).
- **الألوان:** ثلاث ثيمات هادئة (ليل هادئ، ورق دافئ، أزرق ناعم) تُبدَّل من الإعدادات، وتُحفظ لكل جوال.
- لا إشعارات ولا حسابات ولا تنزيل.

## التشغيل (بدون أي إعدادات)
```bash
npm install
npm start     # يبني الواجهة ويشغّل كل شيء على منفذ واحد
```
افتح الموقع: تظهر صفحة «جاهز» فيها زر لفتح رابطك واختيار كلمة سرّ، وبطاقة لإرسال رابطها عبر واتساب أو نسخه. بعد أن تفتح رابطك تُغلق هذه الصفحة نهائيًا. وإن ضاع رابطها ترسله من الإعدادات. لو نسي أحدكما كلمة السرّ: `npm run reset-password a` (أو `b`).

الاستضافة: يلزم خادم Node يشتغل دائمًا على **HTTPS** مع قرص دائم للبيانات (`DATA_DIR`). يوجد `Dockerfile` جاهز (لم أجرّبه). الموقع (GPS) والمايك لا يشتغلان إلا على HTTPS.

## البنية
- `server/` — Express + `ws` + SQLite. الحضور في `live.js`، المسافة في `location.js`، الزجاجات في `bottles.js`، الدخول في `auth.js`.
- `src/` — React + Tailwind v4 + Framer Motion. `HeartStage.tsx` محرّك النبض والمسافة، `Sea.tsx` مشهد البحر، الثيمات في `index.css` و`lib/theme.ts`.
- البيانات والتسجيلات في `server/data/` (خارج git) — احتفظ بنسخة احتياطية منها.
